# Becario del Universo

Juego de microtareas cósmicas para navegador, diseñado para móvil y escritorio. Todo el juego está incluido en `index.html`; no requiere instalación, compilación ni backend.

## Jugar

**GitHub Pages:** https://masugus.github.io/fable5.2-5min-game/

> Esta URL funcionará cuando se active GitHub Pages en el repositorio.

## Activar GitHub Pages

1. Abre **Settings → Pages** en GitHub.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama **develop** y la carpeta **/(root)**.
4. Pulsa **Save**. GitHub publicará automáticamente el archivo `index.html`.

## Controles

- Móvil: tocar y arrastrar sobre la pantalla.
- Escritorio: ratón o teclado según la pantalla de juego.

El récord personal se guarda localmente en el navegador.
